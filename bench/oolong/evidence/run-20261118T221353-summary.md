# OOLONG run 20261118T221353: summary of the numbers

This file holds aggregate numbers only. It holds no transcript text. The numbers come from `results.jsonl` of the run (1,600 units) and were computed again with a script. Means by arm and length are in `run-20261118T221353-by-length.csv`.

## What this run shows

- Date: 2026-11-18.
- Model: `opus` (the main session ran `claude-opus-5-5`; some subagent and llm_map calls ran Sonnet and Haiku). Claude Code 2.1.326.
- Data: OOLONG `trec_coarse`, validation split. 50 tasks at each of 8 context lengths (8K to 1M tokens): 400 tasks per arm. Code grades the answers (no model grader).
- Result: Lossless Handoff with llm_map (arm C) tied plain Claude Code (arm A).
- In this run the main session never compacted (0 compactions in all 1,600 units). The run does not test the handoff. It tests llm_map and the text that the hooks inject at session start.
- No scored result for the handoff's main claim is published yet.

## Paired comparison, arm C minus arm A (same tasks)

The interval is a 95% bootstrap interval over tasks (5,000 resamples).

| Task set | Tasks | Mean A | Mean B | Mean C | C minus A (95% interval) |
|---|---|---|---|---|---|
| All tasks | 400 | 0.711 | 0.730 | 0.731 | +0.02 (-0.01 to +0.05) |
| Clean set | 372 | 0.742 | 0.757 | 0.761 | +0.02 (-0.01 to +0.05) |

Clean set: 28 tasks were removed. The harness checks whether a unit named a file directly in the shared temp folder (`/tmp/claude-<uid>`) in a tool input, because parallel units can overwrite such files. 35 units did this. They belong to 28 different tasks. A task was removed if a unit of any arm did this.

The interval includes 0. The result is a tie.

## Caveats

- The main session never compacted. The run does not test the handoff, and it is not a test of "does the handoff keep what the user said".
- The harness marked this run as INVALID by its own rule: 35 of 1,600 units (2.2%) used the shared temp folder, and the limit was 2%. The clean set above removes the affected tasks. The check is not a proof that the other tasks were not touched.
- Contamination guards of the harness remove more tasks from its stricter "clean" score: 89 of 400 tasks (the control arm answered 67 tasks right without any context, and 23 tasks had a transcript hit, 1 both). This file does not use that stricter set.
- Arm N scored 0.168 with no context. About 1 in 6 label questions can be right by chance.
- One run, one model, one dataset, one machine.
