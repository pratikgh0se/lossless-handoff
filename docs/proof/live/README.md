# Live health evidence

These pages hold the daily live-health evidence of Lossless Handoff from the author's machine. A local script reads the hook logs and the Claude Code transcripts. It is read-only, costs $0 and makes no model call. Each page lists counts and rates only, for the last 7 days and since 2026-11-17, with a verdict for each metric (good, watch or problem). We publish no project names, session ids, paths or chat text, because the repository is public and the projects are private. The numbers come from one heavy user on one machine. They show that the mechanism runs, not that answers get better.
